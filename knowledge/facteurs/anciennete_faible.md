# Facteur de risque : Ancienneté faible (onboarding fragile)

## Signaux
- Ancienneté / tenure faible (client récent).
- Churn concentré sur les premiers mois de la relation.
- Peu d'usage installé, pas encore d'habitude.

## Pourquoi c'est risqué
Les premiers mois sont décisifs : un client qui n'a pas perçu la valeur
rapidement part facilement. Le risque décroît fortement avec l'ancienneté une
fois l'habitude créée.

## Actions recommandées (par priorité)
1. **Onboarding renforcé** : séquence de bienvenue guidée, jalons de prise en
   main, quick wins dès la première semaine.
2. **Point de contact précoce** : vérifier la satisfaction à 30/60/90 jours.
3. **Éducation à la valeur** : montrer concrètement les bénéfices clés.
4. **Offre de fidélité progressive** pour récompenser les premiers mois.

## Message type
« Bienvenue {prénom} ! Pour bien démarrer, voici les 3 choses à faire cette
semaine pour profiter pleinement de {service}. Notre équipe reste disponible. »

## Erreurs à éviter
- Laisser le nouveau client se débrouiller seul.
- Réserver les meilleures offres uniquement aux anciens clients.
