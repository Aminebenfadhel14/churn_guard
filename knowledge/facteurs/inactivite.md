# Facteur de risque : Inactivité / faible engagement

## Signaux
- Client marqué inactif (IsActiveMember = 0), connexions ou transactions rares.
- Baisse de fréquence d'usage sur les dernières semaines/mois.
- Absence d'interaction avec les canaux (app, email, service client).

## Pourquoi c'est risqué
Un client qui n'utilise plus le service se désengage émotionnellement : il ne
perçoit plus la valeur et devient sensible aux offres concurrentes. L'inactivité
est l'un des prédicteurs de churn les plus forts, tous secteurs confondus.

## Actions recommandées (par priorité)
1. **Campagne de réactivation ciblée** : message personnalisé rappelant la
   valeur non utilisée (fonctionnalités, avantages, solde de points).
2. **Offre de reprise en main** : accompagnement, tutoriel, ou petit avantage
   pour recréer l'habitude d'usage.
3. **Appel proactif** d'un conseiller si le client est à forte valeur.
4. **Simplifier le parcours** : lever les frictions qui découragent l'usage.

## Message type
« Bonjour {prénom}, nous avons remarqué que vous utilisez moins {service}
ces derniers temps. Nous aimerions nous assurer que tout vous convient — voici
{avantage/aide} pour tirer le meilleur de votre compte. »

## Erreurs à éviter
- Bombarder de promotions sans comprendre la cause de l'inactivité.
- Attendre que le client parte pour réagir : agir dès les premiers signaux.
