# Facteur de risque : Insatisfaction / mauvaise expérience

## Signaux
- Scores de satisfaction bas (satisfaction au travail, NPS, avis négatifs).
- Réclamations, tickets support, incidents récents.
- Ton négatif dans les échanges.

## Pourquoi c'est risqué
L'insatisfaction est un déclencheur direct et émotionnel de départ. Un problème
non résolu multiplie fortement la probabilité de churn, surtout s'il se répète.

## Actions recommandées (par priorité)
1. **Résolution prioritaire du problème** : traiter la cause racine, pas juste
   le symptôme.
2. **Geste de réparation** : excuse sincère + compensation proportionnée.
3. **Suivi post-résolution** : confirmer que le client est de nouveau satisfait.
4. **Boucle de feedback** : montrer que l'avis a fait bouger les choses.

## Message type
« {prénom}, nous sommes désolés pour {problème}. Voici ce que nous avons fait
pour le corriger : {action}. Nous tenons à vous garder satisfait — {geste}. »

## Erreurs à éviter
- Réponses génériques qui n'adressent pas le vrai problème.
- Compensation sans résolution : le problème reviendra.
