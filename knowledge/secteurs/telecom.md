# Secteur : Télécom / abonnements

Application des facteurs universels au churn télécom (ex. dataset avec tenure,
Contract, MonthlyCharges, InternetService, TechSupport...).

## Profils à risque typiques
- **Contrat mensuel** (sans engagement) : proposer un engagement avantageux.
- **Charges mensuelles élevées** : repositionner la valeur, offre adaptée.
- **Sans support technique / options** : ajouter des services d'ancrage.
- **Ancienneté faible** : onboarding, vérification de la qualité de service.
- **Incidents réseau / réclamations** : résolution prioritaire.

## Actions spécifiques
- Migration vers un forfait mieux adapté à l'usage réel.
- Bundle (internet + mobile + options) pour ancrer la relation.
- Offre de fidélité à l'échéance du contrat.

## Message type
« {prénom}, votre forfait actuel n'est peut-être plus le plus adapté. Voici une
offre {avantage} pensée pour votre usage, avec {service} inclus. »
