# Secteur : Banque / services financiers

Application des facteurs universels au churn bancaire (ex. dataset avec
CreditScore, Geography, Balance, NumOfProducts, IsActiveMember, Tenure...).

## Profils à risque typiques
- **Membre inactif** (IsActiveMember = 0) : réactivation prioritaire.
- **Mono-produit** (NumOfProducts = 1) : cross-sell (épargne, carte, assurance).
- **Solde élevé mais peu engagé** : risque de fuite vers un concurrent ; revue
  patrimoniale personnalisée.
- **Client récent** (faible Tenure) : onboarding et suivi rapproché.
- **Score de crédit faible** : accompagnement financier, produits adaptés.

## Actions spécifiques
- Rendez-vous conseiller pour les clients à forte valeur.
- Offres multi-produits (bundle compte + carte + épargne).
- Programmes de fidélité bancaire, avantages selon l'ancienneté.

## Message type
« {prénom}, votre conseiller souhaite faire le point sur vos {produits} et
vérifier que votre banque répond bien à vos besoins actuels. »
